## 一、故事线（1分钟版）

```
自注意力的成功建立在"输入特征有语义身份"这个隐含前提上
     ↓
PCA匿名化特征失去了语义锚点 → Feature Tokenizer无法学习区分性嵌入
     ↓
Softmax自注意力塌缩为均匀分布（29个特征权重全部≈1/29）
     ↓
修复尝试1: Sparsemax（底层，改归一化函数）
    → 强制稀疏选择 → AUPRC +4.4pp, ECE ×20 → 但只修复症状不修复病因
     ↓
修复尝试2: KD软标签蒸馏（顶层，输出层间接注入）
    → AUPRC +1.68pp → 通过校准改善，不改变注意力分布 → 跨架构安全
     ↓
修复尝试3: TreeReg特征重要性正则化（中间层，嵌入层直接约束）
    → AUPRC -3.73pp!!! → 树的轴对齐偏好结构性替代了注意力的自由交互
     ↓
核心洞察：树归纳偏置与注意力机制基于两种不可通约的"特征重要性"概念
    — 前者是边际独立效应，后者是上下文条件效应
    — TreeReg不是在"引导"注意力，而是在"消灭"注意力
```

## 四、三个核心创新点

### 1. 注意力塌缩的完整诊断（Ch3）
- 权重分布：全部在[0.0327, 0.0342]，std=0.0004
- 多头同质化：任意两头余弦相似度>0.97
- 嵌入低秩：SVD前3个主方向占88.6%方差
- BCE消融排除Focal Loss干扰

### 2. Sparsemax修复与KD的双路径解耦（Ch4+Ch6）
- Sparsemax：底层修复（归一化函数），修复症状
- KD：顶层修复（输出层校准），不干预注意力
- **关键发现**：KD不改变特征重要性排序（r保持0.77-0.79），增益来自校准改善

### 3. 结构性替代概念（Ch7，最重要）
- TreeReg将V14集中度从17.0%→43.9%，r从0.771→0.964
- "树特征重要性 = 边际独立效应 ≠ 上下文条件效应 = 注意力特征重要性"
- TreeReg不是"正则化过强"，是"概念不可通约"

## 五、潜在答辩问题（新版）

### Q1: 跟原来6模型版本的论文比，核心差异是什么？
**A**: 原来试图回答"哪种模型最好"（应用问题），现在回答"自注意力的失效条件是什么以及修复边界在哪里"（机制问题）。前者比较6个模型枚举性能，后者用4个FTT变体的消融链条做因果推断。

### Q2: 为什么不比DeepFM了？
**A**: DeepFM的FM交互与自注意力基于根本不同的归纳偏置。将两者放在"谁更好"的框架下比较，就像比较"汽车和飞机谁更快"而不区分地面和空中。新论文将DeepFM仅作为KD跨架构效应的参考（+1.59pp vs FTT的+1.68pp——印证KD改善的是输出层校准而非架构特定的注意力修复）。

### Q3: TreeReg失败可能只是λ=0.1太大？
**A**: 这是本文的已知局限。但有三层回应：（1）即使λ更小，TreeReg的梯度方向仍然是"align with XGBoost's feature importance"——这是概念层面的不兼容，不是强度问题；（2）λ扫描（0.01/0.05/0.1）是未来工作的明确方向；（3）即使λ=0.01不引起崩塌，论文的核心概念贡献——"树特征重要性与注意力特征重要性的不可通约性"——仍然成立。

### Q4: 注意力塌缩可能是Focal Loss造成的？
**A**: BCE消融实验排除了这一替代解释——BCE训练的FTT注意力分布与Focal Loss版本高度相似。塌缩根因是PCA空间的嵌入同构性。

### Q5: 这个结果在非PCA数据上能复现吗？
**A**: 不知道。这是明确列出的局限。PCA匿名化既是本文的"限制条件"也是"实验控制"——它创造了一个"语义真空"环境，使我们能隔离地研究自注意力对输入表征质量的最低要求。在非匿名化数据上的复制是未来工作。

### Q6: 实际业务中这个研究有什么用？
**A**: 一个警示信号：如果风控系统的数据经过PCA预处理，不要在它上面部署基于自注意力的模型。Sparsemax是必要的最低修复，但不如直接换树模型或非注意力架构。论文的实践指南：PCA数据 → 别用attention；KD → 用软标签别用TreeReg；要注入树先验 → 输出层间接注入，别嵌入层直接约束。

## 六、记忆检查清单（修订版）

- [ ] 四个FTT变体及其AUPRC：A(0.8738)→B(0.9179)→C(0.9347)→D(0.8974)
- [ ] 塌缩定义：所有权重|a_ij - 1/d| ≤ ε，σ ≪ 1/d，JS散度≈0
- [ ] Sparsemax vs Softmax：欧氏投影(可有零) vs 信息论投影(永不为零)

- [ ] "不可通约性"：树=边际独立效应，注意力=上下文条件效应
- [ ] BCE消融：确认PCA空间是塌缩主因，非Focal Loss
- [ ] 实践指南：PCA数据别用attention；KD用软标签别用TreeReg
