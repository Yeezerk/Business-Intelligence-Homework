# LOR-MIM 剖析：打破 PCA 对称性，拯救死掉的注意力

## 前置知识：FT-Transformer 的注意力为什么会"死"？

### 1. 正常的注意力长什么样

想象你在图书馆找书。每本书有一个标签（嵌入向量），你想找"机器学习"相关的书。你的大脑：
- 生成一个 Query："我需要关于 ML 的信息"
- 扫描每本书的 Key："这本书讲什么"
- Query·Key 匹配 → 注意力权重："这本书 30% 相关，那本书 50% 相关..."

关键前提：**每本书的标签有明确的语义身份**（ML书、小说书、历史书——指向不同方向）。

### 2. PCA 匿名化后发生了什么

信用卡数据经过 PCA 处理后，V1~V28 不再是"交易金额"、"商户类别"这些有语义含义的特征，而是**原始特征的各种线性组合**。

类比：不是"ML书"和"小说书"，而是"书1号"到"书28号"——每本书是用 28 本原书的页码加权平均出来的。标签长得差不多，指向几乎相同的方向。

结果：所有 V 特征的 Q·K 内积几乎相同 → 注意力权重全部 ≈ 1/29 ≈ 0.0345 → **注意力死了**。

---

## LOR-MIM 做了什么（人类语言版）

全称：Local Orthogonality Relaxation via Mutual Information-gated Mixup
中文：局部正交松弛——互信息门控混合

### 一句话核心思想

> PCA 让 28 个特征太像了 → 给它们"拌一拌"，让它们彼此有点关系 → 注意力被迫去区分这些差异。

---

## 完整流程

### 第 0 步（训练前，离线执行一次）：给 V 特征分个组

#### 0-1：计算互信息

计算每个 V 特征与 Amount 的互信息（统计相关性），共 28 个 MI 值。

> **诚实说明**：实际上所有 V 特征与 Amount 的 MI 都极低（0.0015~0.0020），几乎相同。所以分组≈随机。但这不重要——"打破对称"需要的不是精确分组，而是**任何形式的非均匀结构**。

**互信息公式**：MI(V_j; Amount) = Σ P(v,a) · log[P(v,a) / (P(v)·P(a))]

它衡量的是：知道一个变量后，对另一个变量的不确定性减少了多少。MI=0 说明两者完全无关，MI 越大说明关系越强。

但 V 特征和 Amount 都是连续值，没法直接数频次，所以需要先**分箱离散化**，再统计概率。完整流程如下：

**① 按列分箱（每个特征各自分）**

V_j 和 Amount 各自在自己的取值范围内等宽切 20 段，把连续值换成箱号：

```
原始数据（150,000行）：
行号    V1        Amount
 1    -1.357      149
 2     0.824        2
 3    -0.561       89
 4     1.203     8900
...

V1 的范围 [-3.5, 3.8]，分20箱，每箱宽 ≈ 0.365：
  箱0: [-3.50, -3.14)   箱1: [-3.14, -2.78)  ...  箱19: [3.44, 3.80]

Amount 的范围 [0, 25691]，分20箱，每箱宽 ≈ 1285：
  箱0: [0, 1285)        箱1: [1285, 2570)    ...  箱19: [24406, 25691]

分箱后：
行号    V1箱号    Amount箱号
 1       10          1
 2       17          0
 3        6          1
 4       15          7
...
```

关键：V1 和 Amount 各分各的箱，不需要在同一尺度上。分箱的目的只是把连续值变成离散标签，好数频次。

**② 按行配对（同一行的两个箱号组成一对）**

因为 V1 和 Amount 来自同一笔交易，所以同一行的箱号天然配对：

```
行1: (V1箱10, Amount箱1) → 格子[10][1] += 1
行2: (V1箱17, Amount箱0) → 格子[17][0] += 1
行3: (V1箱6,  Amount箱1) → 格子[6][1]  += 1
...
150,000行全部投完 → 得到 20×20 频次表
```

**③ 频次 → 概率**

```
联合概率 P(v,a) = 格子频次 / 150000
边缘概率 P(v)   = 行合计 / 150000
边缘概率 P(a)   = 列合计 / 150000
```

**④ 代入公式求和**

对 20×20 = 400 个格子，每个非零格子算 P(v,a)·log[P(v,a)/(P(v)·P(a))]，全部加起来就是 MI。

**⑤ 重复 28 次**

每个 V 特征分别和 Amount 算一次，共 28 个 MI 值。

#### 0-2：构建亲和矩阵

28 个 MI 值归一化到 [0,1]，然后构建 28×28 亲和矩阵：

```
A[i,j] = 1 - |MI_norm[i] - MI_norm[j]|
```

亲和度衡量的是：V_i 和 V_j 与 Amount 的关系模式有多像。MI 值越接近，亲和度越高（接近1）；MI 值差越大，亲和度越低。

```
举例：
V1(0.60) 和 V2(0.00): A = 1 - |0.60 - 0.00| = 0.40  （不太亲）
V1(0.60) 和 V4(0.55): A = 1 - |0.60 - 0.55| = 0.95  （很亲）
V1(0.60) 和 V1(0.60): A = 1 - 0 = 1.00  （自己和自己是1）
```

为什么 28 个 MI 值就能填满 28×28 矩阵？因为亲和度不需要新信息，只是 28 个数两两做减法。类比：你有 28 个人的身高，不需要额外量任何东西就能算出"任意两个人的身高差"——28 个数据足以生成 28×28 的差值矩阵。

#### 0-3：谱聚类分组

在亲和矩阵上做谱聚类，把 28 个特征分成 K=5 组。谱聚类的核心思想：**把"谁和谁亲"的关系图，变成空间位置，再在空间里聚类**。

**① 建图**

把亲和矩阵看作一张关系网：28 个节点（V1~V28），节点 i 和 j 之间有一条边，权重 = A[i,j]。A[i,j]≈1 是粗线（很亲），A[i,j]≈0 是细线或无线（不亲）。

**② 度矩阵 D**

每个节点的"总亲密度"——所有连向它的边的权重之和：

```
D[i,i] = Σ_j A[i,j]

D 是对角矩阵：
D = | 12.5  0    0   ... |
    |  0   11.8  0   ... |
    |  0    0   13.2 ... |
    | ...  ...  ...  ... |
```

**③ 拉普拉斯矩阵 L = D - A**

对角矩阵减去亲和矩阵。L 本身不能直接告诉你谁和谁一组，它只是编码了关系结构，分组信息隐藏在整体模式里，需要特征分解来"解码"。

**④ 特征分解（最关键的一步）**

对 L 做特征分解，取最小的 K-1=4 个非零特征值对应的特征向量：

```
v1, v2, v3, v4，每个是 28 维
拼起来 → 28×4 坐标矩阵

      维度1    维度2    维度3    维度4
V1    0.12    0.05   -0.09    0.03
V2   -0.08    0.11    0.07   -0.14
V3    0.15   -0.03    0.02    0.06
...
V28   0.04   -0.06    0.08    0.01
```

每个 V 特征现在有了 4 维坐标——这就是从"关系图"到"空间位置"的转换。原来在亲和矩阵里很亲的两个特征，在 4 维空间里距离很近；不亲的特征距离很远。

**⑤ K-means 分组**

在 4 维坐标空间里做 K-means，分 5 组：

```
组0: [V1, V5, V9, V12, V18, V22, V25, V27, V28]   → 9个
组1: [V2, V6, V10, V14, V17, V20, V23, V26]        → 8个
组2: [V3, V7, V11, V15]                             → 5个
组3: [V4, V8]                                       → 3个
组4: [V13, V16, V19]                                → 3个
```

为什么不直接对 28 个 MI 值做 K-means？直接 K-means 只看每个 V 特征自己的 MI 值（1维信息），而谱聚类利用了亲和矩阵的全局结构（28维信息→降维到4维→聚类），能捕捉"链式结构"（A亲B，B亲C，A不太亲C）等复杂关系。

**三步各自的角色**：

```
L = D - A   → 编码了关系结构，但看不出来
特征分解     → 把结构翻译成空间坐标
K-means     → 在坐标空间里找自然分组
```

缺任何一步都不行：只有 L → 信息在里面但读不出来；只有特征向量 → 有坐标但没分组；只有 K-means → 没有好的坐标，分出来的组没意义。

**到这里，分组完成。以下进入训练阶段。**

---

### 第 1 步（每笔交易）：门控网络决定"这次怎么拌"

```
Amount → MLP(1→16→5) → Softmax → α = [0.28, 0.25, 0.18, 0.14, 0.15]
```

**输入**：这笔交易的 Amount（1个数）

**经过**：一个两层 MLP
- 第1层：1 → 16（1个金额扩展到16个隐层神经元）
- 激活函数：ReLU
- 第2层：16 → 5（输出5个数，对应5个组）
- Softmax：把5个数归一化，和为1

**输出**：5 个权重 α，含义是"这笔交易的金额下，各组混合结果的贡献比例"

```
金额=10元    → α = [0.30, 0.25, 0.20, 0.15, 0.10]  ← 小额交易，组0贡献大
金额=5000元  → α = [0.10, 0.15, 0.25, 0.30, 0.20]  ← 大额交易，组3贡献大
```

不同金额 → 不同配方，这就是"互信息门控"的"门控"部分。

**门控网络学什么**：初始化时对所有金额 α≈均匀，训练后学会不同金额下各组的贡献比例。

---

### 第 2 步：组内混合（打破对称性的核心）

每组有一个可学习矩阵 M_k（初始化为单位阵 I + 小噪声）：

```
V'_组k = M_k · V_组k
```

例如组0有9个特征，M_0 是 9×9 矩阵，V_组0 是这9个特征的数值。混合后每个新特征 = 组内其他特征的线性组合。

**初始化**：M_k ≈ 单位阵（对角线≈1，非对角线≈0.02），几乎不混合：

```
M_0 初始化：
  | 1.00  0.02  0.01 ... |     ← 对角线≈1，自己占主导
  | 0.03  1.00  0.04 ... |     ← 非对角线≈0.02，轻微掺入别人
  | 0.01  0.03  1.00 ... |
  ...
```

**训练后**：梯度调整 M_k 的每个元素，模型自己学"混多少、怎么混"：

```
M_0 训练后可能变成：
  | 0.85  0.08  0.12 ... |     ← 对角线下降，自己占比减少
  | 0.15  0.90  0.06 ... |     ← 非对角线上升，掺入更多别人
  | 0.10  0.05  0.88 ... |
  ...
```

展开看混合效果：

```
V1' = 0.98·V1 + 0.03·V5 + 0.01·V9 + ...  （V1' 里掺了 V5 的成分）
V5' = 0.03·V1 + 0.95·V5 + 0.04·V9 + ...  （V5' 里掺了 V1 的成分）
```

每个特征不再是独立的，它们之间有了**弱相关性**。

---

### 第 3 步：加权拼接

```
5个组的混合结果分别乘以门控权重α：
  组0输出 × α_0 (0.28)
  组1输出 × α_1 (0.25)
  组2输出 × α_2 (0.18)
  组3输出 × α_3 (0.14)
  组4输出 × α_4 (0.15)

拼接 → 28维（但顺序是组0,组1,组2,组3,组4）
  ↓ 逆排列还原
28维（V1, V2, V3, ..., V28 顺序）
  ↓ 拼上 Amount
29维向量
```

---

### 第 4 步：送入 FT-Transformer

```
变换后的29维向量 → FT-Transformer → 欺诈概率
```

FT-Transformer 的结构和参数**完全不变**，LOR-MIM 只是在它前面加了一个预处理层。

---

### 参数量

```
门控网络：1×16 + 16 + 16×5 + 5 = 101 个参数
混合矩阵：9×9 + 8×8 + 5×5 + 3×3 + 3×3 = 81+64+25+9+9 = 188 个参数
总计：约 305 个可训练参数（含偏置项）
```

占 FT-Transformer 总参数的 **0.15%**，几乎可以忽略。

## 训练：损失函数与端到端优化

### 损失函数：Focal Loss

LOR-MIM + FT-Transformer 使用 **Focal Loss**，不是普通的交叉熵。公式：

```
FL(p_t) = -α_t · (1-p_t)^γ · log(p_t)
```

| 部分 | 含义 |
|------|------|
| `log(p_t)` | 标准交叉熵，分错越狠损失越大 |
| `(1-p_t)^γ` | 聚焦权重，分得好的样本损失被压低，分得差的保留 |
| `α_t` | 类别权重，欺诈样本(y=1)权重=0.25，正常样本(y=0)权重=0.75 |

#### 为什么不用普通交叉熵

数据极度不平衡（欺诈仅 0.5%），普通交叉熵会被大量正常样本主导——模型只要全猜"正常"就能有很低的 loss。

Focal Loss 的 `(1-p_t)^γ` 解决这个问题：

```
一笔正常交易，模型很确定地分对了（p_t=0.99）：
  普通CE：  loss = 0.01        ← 虽然小但15万个样本加起来很大
  Focal：   loss = 0.01 × (1-0.99)^2 = 0.01 × 0.0001 = 0.000001  ← 几乎为0

一笔欺诈交易，模型分错了（p_t=0.3）：
  普通CE：  loss = 0.52
  Focal：   loss = 0.52 × (1-0.3)^2 = 0.52 × 0.49 = 0.255  ← 保留大部分
```

效果：模型不再被大量简单负样本淹没，被迫关注那些难分的欺诈样本。

### 端到端训练

```
输入一笔交易（29维）
  ↓
LOR-MIM 变换（门控 + 混合，305个可学习参数）
  ↓
FT-Transformer 分类（~20万个可学习参数）
  ↓
输出 logits
  ↓
Focal Loss 计算损失
  ↓
梯度回传，同时更新 LOR-MIM 和 FT-Transformer 的参数
  ↓
重复直到收敛
```

LOR-MIM 和 FT-Transformer **一起学**，不是分开训练的。分组固定，但混合方式（M_k）和门控配方（α）与分类能力联合优化。

## 为什么它让注意力"活过来"了？

### 核心机制：对称性破缺

PCA 空间中，29 个 token 对 Transformer 来说像 29 个**完全一样的球**。注意力机制无从下手。

LOR-MIM 通过混合矩阵在组内引入**特征间的弱相关性**：
- 之前：V1 和 V2 完全不相关（PCA 正交的结果）
- 之后：V1' = 0.98·V1 + 0.03·V2 + 0.01·V5 + ...（轻微混合）

每个 V 特征不再独立。Transformer 的 Q·K 内积现在会产生**可区分的差异**。

注意力 std 从 0.00125（完全塌缩）涨到 0.01401（40.6% 均匀基线），提升了 **×11.2**。

## 实验结果：五个模型的完整对比

| 模型 | AUPRC | AttnStd | 注意力多样性 | 解读 |
|------|:-----:|:-------:|:----------:|------|
| Softmax | 0.9126 | 0.00125 | ×1 | 塌缩基线 |
| Sparsemax | 0.9384 | 0.00942 | ×7.5 | 归一化端修复 |
| BCE | 0.9491 | 0.00408 | ×3.3 | 损失端修复 |
| LOR-MIM+Softmax | 0.9242 | 0.01401 | **×11.2** | 数据端修复，多样性最高 |
| LOR-MIM+Sparsemax | 0.9267 | 0.02064 | **×16.5** | 联合修复，但 AUPRC 反降 |

---

## 最核心的发现：注意力"活过来"≠注意力"变有用"

LOR-MIM 把注意力多样性恢复了 ×11.2（是所有方法中最高的），但 AUPRC 只从 0.9126 提升到 0.9242（+1.2pp），远不如 Sparsemax（+2.6pp）和 BCE（+3.7pp）。

**为什么？**

LOR-MIM 的混合让特征间产生了差异 → 注意力确实能区分特征了 → 但这些差异来自**混合矩阵的随机结构**，不是来自特征本身对分类有用的信息。

打个比方：
- Sparsemax 是一个**能力有限但方向正确**的学生——他只看"真正有判别力"的少量特征
- LOR-MIM 是一个**什么都看但判断不准**的学生——他关注了更多特征，但分不清哪些真正重要

**更关键的是**：LOR-MIM + Sparsemax 的联合使用比 Sparsemax 单独使用**更差**（0.9267 vs 0.9384）。这说明数据端修复（LOR-MIM 打破对称）和归一化端修复（Sparsemax 稀疏选择）之间存在**结构性拮抗**——LOR-MIM 的混合破坏了 Sparsemax 赖以工作的 logits 排序结构。

---

## 论文中的定位

LOR-MIM 不是一个"更好的方法"——它是一个**诊断工具**。它的价值在于：

1. **证明注意力塌缩确实来自 PCA 对称性**（因为打破对称就能让注意力活过来）
2. **证明注意力多样性与分类性能非线性**（×11.2 多样性 ≠ ×11.2 性能）
3. **揭示数据端和归一化端修复的拮抗关系**（联合不如单独）

这三个发现加在一起，比一个"更好的模型"更有学术价值。
