# 树监督学习与归纳偏置迁移（Tree-Supervised Neural Networks）

> 为什么 FT-Transformer 的注意力在 PCA 空间中塌缩为均匀分布？如何将 XGBoost 的轴对齐归纳偏置迁移到深度神经网络？本文档梳理从知识蒸馏到树正则化嵌入的完整技术路径。

---

## 〇、动机：FTT 注意力塌缩的根本原因

### 问题

在 2026-06-07 的实验中，FT-Transformer 的 [CLS] Token 对 29 个特征的注意力权重全部集中于 $[0.0327, 0.0342]$（均值 0.0334），与均匀基线 $1/29 = 0.0345$ 几乎重合，标准差仅 0.0004。该现象导致原始 Softmax FTT 的 AUPRC 仅为 0.8401。引入 Sparsemax 后 AUPRC 提升至 0.9179，但注意力仍近乎均匀——说明 PCA 空间本身缺乏注意力可利用的语义结构。树监督蒸馏正是为此设计的：用 XGBoost 的外部特征重要性信号弥补注意力自身的盲区。

### 根因分析

1. **Softmax 的温度效应**：Softmax 将 Query-Key 内积映射为概率分布。在 PCA 空间中，各特征向量 $W_j$ 的方差趋近，Query-Key 内积退化为接近常数的向量 → Softmax 输出趋近 $1/d$ 的均匀分布
2. **PCA 破坏语义锚点**：原始特征（交易时间、金额、商户类别）的语义关联在 PCA 的正交基中不可逆地丧失。多头注意力的每个"头"本应学习不同的特征子空间划分，但在缺乏语义锚点的情况下，8 个头的内积分布高度重叠，无法形成差异化
3. **Focal Loss α=0.995 的副作用**：极端类别权重（~200:1）使模型将有限的梯度预算几乎全部投入少数类样本的分类边界调整，注意力权重的梯度信号被淹没

### 解决思路

→ 让神经网络**从 XGBoost 中学习特征的相对重要性**，而非自行从头发现。XGBoost 的轴对齐分裂天然适合 PCA 特征（每个分裂沿单一特征维度的阈值），其分裂增益（split gain）直接量化了各特征在分类决策中的贡献。

## 一、理论基础：知识蒸馏框架

### 1.1 经典知识蒸馏（Hinton et al., 2015）

知识蒸馏允许"学生"网络从"教师"网络的软标签中学习：

$$L_{KD} = \alpha \cdot L_{CE}(y_{pred}, y_{true}) + (1-\alpha) \cdot T^2 \cdot L_{KL}(p_{student}^T, p_{teacher}^T)$$

其中 $T$ 为温度参数，$p^T$ 为温度缩放后的概率分布：
$$p_i^T = \frac{\exp(z_i / T)}{\sum_j \exp(z_j / T)}$$

- **高 $T$ (T>1)**：软化分布，暴露类别间的相对关系（"欺诈样本在正常/欺诈边界上的不确定性"）
- **低 $T$ (T→1)**：趋于硬标签，仅保留"是/否欺诈"二元信号

### 1.2 为什么树→NN蒸馏对表格数据特别有效

Lee et al. (2023) 在 *Practical Knowledge Distillation* 中证明：

1. **数据蒸馏 + 模型蒸馏两步优于单步**：先用 GBDT 生成增强数据，再用软标签训练 NN
2. **等价性定理**：当学生模型容量足够时，GBDT→NN 的软标签蒸馏等价于在 GBDT 的叶子分布上进行 KL 散度最小化——两者在期望意义上收敛到同一最优解
3. **关键结论**：在 10 万+样本量下，蒸馏后的 DNN 可以**接近甚至超越** GBDT 教师——知识蒸馏不仅迁移了预测能力，还迁移了 GBDT 的归纳偏置（轴对齐决策边界）

### 1.3 本项目的蒸馏框架

传统 KD 是"大模型→小模型"的压缩。本项目是 **"异质模型→同容量NN"的归纳偏置迁移**：

$$XGBoost（轴对齐分裂）\xrightarrow{软标签+特征重要性} Neural Network（分布式表征）$$

核心创新点：不是让 NN 学得更像 NN（传统 KD），而是让 NN 学得更像树。

## 二、关键文献梳理

### 2.1 DeepTLF（Borisov et al., 2023）— 结构化树编码

```
DeepTLF = GBDT Ensemble + TreeDrivenEncoder + DNN

TreeDrivenEncoder 流程：
  输入 x → 遍历每棵树的每个内部节点
         → 评估 x 在每个节点的布尔分裂函数 (x[feat] > threshold?)
         → 将布尔结果连接为二进制向量 v ∈ {0,1}^{#内部节点}
         → DNN 在此同质化向量上训练
```

**核心洞察**：树的结构信息（哪些特征在哪些阈值被分裂）是 GBDT 归纳偏置的可表示化形式。将此结构信息注入 NN 的输入层，等效于给 NN 提供了"在这个数据上，树模型是如何理解的"先验知识。

**对 3B 的启示**：XGBoost 的 `(feature_index, threshold)` 对可直接编码为 embedding 层的初始化或正则化约束。

### 2.2 Tree-Regularized Tabular Embeddings（Li et al., 2024）— 特征嵌入正则化

NeurIPS 2023 工作，亚马逊团队在 88 个 OpenML 数据集上验证：

- **T2V（Tree-to-Vector）**：每棵树的节点阈值 $(\text{var}_i, \theta_j)$ 作为一对布尔特征 → 拼接为向量
- **T2T（Tree-to-Token）**：每棵树嵌入为一个 token → Transformer 编码器处理
- **核心发现**：T2T+注意力在 88/91 数据集上优于 SAINT（59/91），且无需复杂架构

**对 3B 的启示**：树的阈值信息可作为 NN 特征嵌入层的外部先验。本项目不需要完整的 T2V/T2T 变换——只需将 XGBoost 的分裂增益作为嵌入层的正则化权重。

### 2.3 Practical Knowledge Distillation（Lee et al., 2023）— 表格数据蒸馏系统研究

- 在 100K+ 样本上，蒸馏后的 DNN **缩小了与 GBDT 的性能差距**
- 在小样本（<10K）上，蒸馏后的 DNN **超越了 GBDT 教师**
- 数据蒸馏（生成合成样本）+ 模型蒸馏（软标签）两步优于单步

**对 3A 的启示**：本项目有 15 万样本，处于论文的"大样本区间"——蒸馏预计可将 DNN 性能提升至接近 XGBoost 水平。

## 三、方案 3A：Leaf Soft Label Distillation（实现路径）

### 3.1 原理

XGBoost 的 300 棵树的叶子节点分布携带了比硬标签（0/1）更丰富的信息：

- **叶子位置**：样本落在第 $k$ 棵树的第 $l$ 个叶子，反映该样本在树结构中的"决策路径"
- **叶子值**：该叶子的预测值（log-odds），是所有落入该叶子的训练样本的加权平均
- **软标签**：$p_{teacher} = \sigma(\sum_k leaf\_value_k)$

XGBoost 的软标签比硬标签更**平滑**：
- 硬标签（0/1）：完全信任标注，忽略样本在边界上的模糊性
- XGBoost 软标签：边界样本的预测概率接近 0.5，反映了模型对此样本的不确定性
- NN 学习这种平滑分布，继承了 XGBoost 对特征空间的"轴对齐"决策边界的理解

### 3.2 损失函数

$$L = \alpha \cdot FL(y_{pred}, y_{true}) + (1-\alpha) \cdot T^2 \cdot KL(p_{student}^T \| p_{teacher}^T)$$

其中：
- $FL$ 为 Focal Loss（保留类别不平衡处理）
- $KL$ 为 Kullback-Leibler 散度
- $T$ 为温度（推荐 4.0，理由：极度不平衡下软标签已经很尖锐，需更高温度将边界不确定性暴露出来）
- $\alpha$ 为硬标签权重（推荐 0.7，保留 30% 的蒸馏信号）

### 3.3 实现步骤

```python
# Step 1: 从已训练的 XGBoost 获取软标签
xgb_model = xgb.XGBClassifier()
xgb_model.load_model("xgb_baseline.json")
xgb_probs = xgb_model.predict_proba(X_train)[:, 1]  # shape: (N,)
teacher_logits = np.log(xgb_probs / (1 - xgb_probs))  # prob → logit

# Step 2: 将 teacher logits 存入 DataLoader
train_dataset = TensorDataset(X_train, y_train, teacher_logits_tensor)

# Step 3: 训练时计算 KL 散度
def distillation_loss(student_logits, y_true, teacher_logits, T, alpha):
    # Hard label loss (Focal)
    loss_hard = focal_loss(student_logits, y_true)
    # Soft label loss (KL with temperature)
    student_T = (student_logits / T).sigmoid()
    teacher_T = (teacher_logits / T).sigmoid()
    loss_soft = T**2 * kl_div(student_T, teacher_T)
    return alpha * loss_hard + (1-alpha) * loss_soft
```

### 3.4 预期效果

基于 Lee et al. (2023) 在 100K+ 样本量上的实验结果：
- 蒸馏后 DNN 的 AUPRC 预计提升 2-5 个百分点
- FTT 可从 0.8738 → 0.89-0.91
- DeepFM 可从 0.9174 → 0.92-0.93（接近 XGBoost 的 0.9331）

## 四、方案 3B：Feature Split Importance Regularization（实现路径）

### 4.1 原理

XGBoost 在训练过程中计算每个特征的 **split gain**（分裂增益）——该特征在所有树中被选为分裂节点时带来的损失下降之和。
Normalize 后得到特征重要性向量 $\mathbf{w} \in [0,1]^d, \sum w_i = 1$。

将此作为 NN 嵌入层的特征重要性先验：
- **高 $w_i$ 的特征**（如 V14, w≈0.65）：允许更大的嵌入参数范数，模型可分配更多容量
- **低 $w_i$ 的特征**（如 V23, w<0.01）：施加 L1 收缩，鼓励模型忽略噪声维度

### 4.2 正则化项

在 NN 训练损失中加入树引导的特征嵌入正则化：

$$L_{reg} = \lambda \sum_{i=1}^d \underbrace{(1 - w_i)}_{\text{低重要性→高惩罚}} \cdot \underbrace{\|E_i\|_2}_{\text{嵌入范数}}$$

其中 $E_i \in \mathbb{R}^{d_{model}}$ 为第 $i$ 个特征的嵌入向量，$\lambda$ 为正则化强度。

### 4.3 实现（对 FT-Transformer FeatureTokenizer 的修改）

```python
class FeatureTokenizerWithTreePrior(nn.Module):
    def __init__(self, input_dim, d_model, feature_weights):
        super().__init__()
        self.W = nn.Parameter(torch.empty(input_dim, d_model))
        self.bias = nn.Parameter(torch.zeros(input_dim, d_model))
        # feature_weights: XGBoost split gain, normalized to [0,1]
        self.register_buffer('feature_weights', feature_weights)
        nn.init.kaiming_uniform_(self.W, a=5**0.5)

    def forward(self, x):
        return x.unsqueeze(-1) * self.W.unsqueeze(0) + self.bias.unsqueeze(0)

    def tree_regularization_loss(self):
        """L_reg = λ Σ (1 - w_i) * ‖E_i‖₂"""
        per_feature_norm = self.W.norm(dim=1)  # (input_dim,)
        penalty = (1 - self.feature_weights) * per_feature_norm
        return penalty.sum()
```

### 4.4 与方案 3A 的结合

$$
L_{total} = \underbrace{\alpha \cdot FL(y_{pred}, y_{true})}_{\text{Focal Loss}} + \underbrace{(1-\alpha) T^2 KL(p_s^T \| p_t^T)}_{\text{3A: Soft Label Distillation}} + \underbrace{\lambda \sum (1-w_i)\|E_i\|_2}_{\text{3B: Tree Prior Regularization}}
$$

三条损失各自的角色：
1. **Focal Loss**：类别不平衡 → 少数类梯度权重
2. **KD 损失**：树模型的决策边界 → 软标签
3. **树先验正则化**：树模型的特征重要性 → 嵌入层结构

## 六、实验结果（2026-06-08 最终）

### 6.1 实测结果

| 模型 | AUPRC | vs 基线 | ECE | Cost | 结论 |
|------|-------|---------|-----|------|------|
| XGBoost（教师） | 0.9331 | — | 0.0006 | 215 | 强基线 |
| FTT（Sparsemax 基线） | 0.9179 | — | 0.0120 | 99 | Sparsemax 大幅改善 |
| DeepFM（基线） | 0.9336 | — | 0.0394 | 123 | 与 XGBoost 持平 |
| FTT + KD（3A only） | **0.9347** | **+1.68pp** | 0.0007 | 97 | ✅ KD 对 FTT 有效！ |
| FTT + KD + TreeReg（3A+3B） | 0.8974 | **-3.73pp vs FTT+KD** | 0.0010 | 169 | ❌ TreeReg 是元凶 |
| DeepFM + KD（3A only） | **0.9495** | **+1.59pp** | 0.0008 | 120 | ✅ 全局最优 |

### 6.2 关键发现（v2 — 消融后修正）

1. **软标签蒸馏跨架构有效**：FTT+KD（+1.68pp）和 DeepFM+KD（+1.59pp）的提升幅度高度一致，推翻了此前"蒸馏是架构依赖的"初步判断。KD 是跨架构安全的性能倍增器。

2. **TreeReg 是退步的唯一元凶**：FTT+KD+TreeReg 的 AUPRC（0.8974）不仅低于 FTT+KD（0.9347），甚至低于未蒸馏的 FTT 基线（0.9179）。从 0.9347 到 0.8974 的 -3.73pp 断崖式下降，将因果链条唯一锁定于 TreeReg——树先验对嵌入层的刚性约束（V14 权重=1.0）与 Sparsemax 注意力的自由交互学习形成结构性拮抗。

3. **KD 信号对 FTT 的校准和性能均有实质贡献**：FTT+KD 的 ECE=0.0007（近乎完美），验证了软标签中的"暗知识"通过温度软化成功传递了决策边界信息。软标签部分独立有效（ECE 改善），TreeReg 部分独立有害（AUPRC 崩溃）——两者效应完全可分离。

4. **校准的跨架构一致提升**：所有 KD 变体均达 ECE < 0.002，与架构选择和 TreeReg 的存在均无关——这是 KD 最稳健的收益。
