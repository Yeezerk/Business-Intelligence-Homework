# 01 — 类别不平衡处理全景

> **核心问题**：欺诈交易只占 0.1%-1%。如果一个模型把所有交易都预测为"正常"，准确率 99%+，但对业务毫无价值。这就是类别不平衡的核心矛盾。

---

## 1. 为什么不平衡是问题？

### 1.1 一个具体的例子

假设数据集有 100,000 笔交易：
- 正常：99,000（99%）
- 欺诈：1,000（1%）

**模型A（全猜正常）**：
- 准确率 = 99%
- 查全率（Recall）= 0%（一个欺诈都没抓到）

准确率公式：$\text{Accuracy} = \frac{TP + TN}{TP + TN + FP + FN}$

查全率公式：$\text{Recall} = \frac{TP}{TP + FN}$

查准率公式：$\text{Precision} = \frac{TP}{TP + FP}$

混淆矩阵：

|          | 预测为正类  | 预测为负类  |
| -------- | ----------- | ----------- |
| 实际正类 | TP (真正例) | FN (假负例) |
| 实际负类 | FP (假正例) | TN (真负例) |

- → 这是"高准确率的废模型"

**模型B（抓到 800 欺诈，误报 2000 正常）**：
- 准确率 = 96.8%（看起不如模型A！）
- 查全率 = 80%

此处 Recall = 800 / 1000 = 80%，符合上述公式。

- → 这反而是有用的模型

### 1.2 三个层面的危害

| 层面     | 具体影响                                                       |
| -------- | -------------------------------------------------------------- |
| **训练** | Loss 被正常样本主导，梯度更新方向忽略欺诈                      |
| **评估** | Accuracy/ROC-AUC 等指标被正常类"绑架"，给出虚假的安全感        |
| **业务** | 漏掉欺诈（FN）的损失远超误报（FP），但模型没有被教会这个优先级 |

---

## 2. 三大解决流派

```
类别不平衡处理
├── 数据层面：改变训练集的类别分布
│   ├── 欠采样 (Under-sampling)：丢弃多数类样本
│   ├── 过采样 (Over-sampling)：复制少数类样本
│   └── SMOTE：在少数类样本间插值生成合成样本
│
├── 算法层面：改变模型"看待"不同类别的方式
│   ├── Class Weight：在损失函数中给少数类更高权重
│   └── Cost-Sensitive Learning：直接优化业务成本
│
└── 损失函数层面：重新设计损失函数
    └── Focal Loss：动态降低"易分类样本"的损失贡献
```

---

## 3. 各方法详解

### 3.1 欠采样 (Under-sampling)

**做法**：从正常交易中随机丢弃大部分，使正负比例接近 1:1

```
原始：正常 99,000 + 欺诈 1,000
欠采样后：正常 1,000 + 欺诈 1,000
```

**优点**：简单，训练快（数据量减少）

**缺点**：丢弃了 98,000 条正常交易的信息！模型学不到"正常交易长什么样"的完整分布。

### 3.2 随机过采样 (Random Over-sampling)

**做法**：随机复制欺诈样本直到正负平衡

```
原始：正常 99,000 + 欺诈 1,000
过采样后：正常 99,000 + 欺诈 99,000（复制 99 次）
```

**优点**：保留了所有正常交易信息

**缺点**：模型会"记住"特定的欺诈样本而不是学到欺诈模式（严重过拟合）。

### 3.3 SMOTE (Synthetic Minority Over-sampling Technique)

**核心思想**：不是简单复制，而是在欺诈样本之间"插值"生成新样本。

**算法**：对每个欺诈样本 x：
1. 找到它的 k 个最近邻（在欺诈类中）
2. 随机选一个邻居 x_nn
3. 在连线上随机插值：x_new = x + λ(x_nn - x)，λ ~ U(0,1)

**优点**：生成的样本比简单复制有更多"变化"。

**缺点**：
- 如果少数类样本本身很稀疏，插值生成的可能不代表真实欺诈
- 对高维数据效果下降（维度灾难）
- 训练时间增加

**为什么高维数据效果下降**：在高维空间中，所有点间距离趋向相等。例如100维空间中，最近邻距离~0.057，第100近邻距离~0.063，比值~0.90——邻居选择实际接近随机。这导致SMOTE的插值方向可能指向多数类密集区域，而非少数类内部。

### 3.4 Class Weight

**做法**：在损失函数中，给欺诈类的损失乘以一个较大的权重

L_weighted = -w1 * y * log(p) - w0 * (1-y) * log(1-p)

其中 w1 = N_total / (2 * N_fraud)（inverse frequency）

**优点**：最简单，一行代码

**缺点**：对所有欺诈样本一视同仁——无论模型已经很好地分类了它，还是完全搞错了。无法区分"易分类"和"难分类"样本。

### 3.5 Focal Loss

**核心创新**：不仅区分"正类 vs 负类"，还区分"易分类 vs 难分类"。

FL(p_t) = -α_t * (1-p_t)^γ * log(p_t)

- p_t：模型对正确答案的置信度
- 当 p_t 很大（模型很自信且正确），(1-p_t)^γ 很小 → 降低这个样本的损失
- 当 p_t 很小（模型不确定或错了），(1-p_t)^γ 接近 1 → 保持原有损失

**直觉**：你已经会了的题就少做，多做你不会的。

**易分类 vs 难分类的区分**：由模型预测置信度 p_t 决定。p_t ≈ 0.99（极确信）→ 易分类样本；p_t ≈ 0.5（模棱两可）或 p_t ≈ 0.1（确信但可能错）→ 难分类样本。Focal Loss 通过 (1-p_t)^γ 动态调节：易分类样本损失被大幅压缩，难分类样本损失保持。

详见 notes/02_Focal_Loss深度解析.md

## 4. 方法对比总结

| 方法           | 数据量 | 训练速度 | 过拟合风险 | 实现复杂度 | 适用场景         |
| -------------- | ------ | -------- | ---------- | ---------- | ---------------- |
| 欠采样         | 减少   | 快       | 低         | ★          | 数据量极大时     |
| 过采样         | 增加   | 慢       | 高         | ★          | 数据量小时慎用   |
| SMOTE          | 增加   | 慢       | 中         | ★★         | 低维数据         |
| Class Weight   | 不变   | 不变     | 低         | ★          | 通用基线         |
| **Focal Loss** | 不变   | 不变     | 低         | ★★         | **深度模型首选** |

## 6. 常见误区

1. **"先 SMOTE 再划分数据集"** → 数据泄露！SMOTE 只能在训练集上做
2. **"Accuracy 99% 模型很好"** → 在不平衡数据上 Accuracy 是最没用的指标
3. **"把数据平衡到 1:1 就对了"** → 不一定。真实世界中欺诈就是 1%，强制 1:1 可能导致模型对正常交易误判率过高
4. **"只用一种方法"** → 可以组合：Focal Loss + Mild SMOTE 有时效果更好

## 本项目实验发现（2026-05-30 更新）

### SMOTE 在 PCA 匿名化特征上的反向效果

本项目消融实验发现了一个反直觉的结果：

| 策略 | TabNet AUPRC |
|------|-------------|
| Focal Loss ($\alpha$=0.25) | **0.8737** |
| Class Weight | 0.8732 |
| Plain CE | 0.8676 |
| SMOTE (1:1) | **0.7839** ❌ |

SMOTE 非但没有提升，反而导致 AUPRC 暴跌 8.98pp。原因分析：

1. **PCA 协方差破坏**：SMOTE 在 PCA 特征空间中通过线性插值生成合成样本，破坏了 PCA 成分间原始的协方差正交结构。PCA 成分本来是不相关的（协方差矩阵为对角阵），但 SMOTE 插值生成的样本引入了虚假相关性。

2. **TabNet 注意力失效**：TabNet 的 Sparsemax 稀疏特征选择依赖特征间的统计规律。SMOTE 合成样本的噪声/虚假模式使注意力掩码难以学习有意义的稀疏模式，导致"注意力迷失"。

3. **合成噪声放大**：TabNet 的高敏感性特征选择机制（每个决策步只关注少数特征）会将合成样本中的噪声放大——如果"关注"到的是噪声特征而非真实信号。

**教训**：SMOTE 不是万能药。当特征经过 PCA/降维处理、或特征空间具有严格几何结构时，SMOTE 可能适得其反。
